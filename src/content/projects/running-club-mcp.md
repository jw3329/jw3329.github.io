Running Club MCP is an **open-source Garmin dashboard for my running club** that doubles as a set of **MCP tools for Claude**, so members can ask Claude about their own training.

## How it works

- **One app per member** — download for Mac or Windows, log in with your own Garmin account, and the dashboard opens in your browser
- **Private by design** — no central server and no sign-up; the session and data stay on each member's machine
- **One-click Claude connection** — a button on the dashboard registers the MCP server with Claude Desktop, with no config files to edit
